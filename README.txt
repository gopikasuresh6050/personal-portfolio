GOPIKA — CINEMATIC PERSONAL PORTFOLIO

This is a starter portfolio for an Electronics & Communication Engineering student who is also a photographer and video editor.

FILES
- index.html: website structure and portfolio copy
- style.css: styling, responsive layout, cinematic design
- script.js: cursor-based 2.5D portrait movement and floating particles
- red.png: full-screen hero background image
- anime-me.png: original portrait asset

RUN LOCALLY
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Install the "Live Server" extension if needed.
4. Right-click index.html and select "Open with Live Server".
5. Move the cursor over the hero to test the background movement.

PERSONALIZE
- Update the name, bio and study details in index.html.
- Keep red.png in the same folder as index.html; it is used for the full-screen hero background.
- Replace your-email@example.com with your email.
- Replace sample cards/placeholders with your real ECE projects, photos, edits and showreel links.
- Add social links such as Instagram, LinkedIn and GitHub when ready.

ANIMATION NOTE
The full-screen hero background moves subtly with the cursor; this interaction is disabled when reduced motion is enabled.
